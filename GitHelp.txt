команды для работы с коммитами

1. Просмотр истории
Команда	Описание
git log	Полная история коммитов
git log --oneline	Краткая история коммитов
git log --oneline -5	Последние 5 коммитов
git reflog	История перемещения HEAD, помогает восстановить потерянные коммиты

2. git reset — откат коммитов
Команда	Описание
git reset --soft HEAD~1	Удаляет последний коммит, изменения остаются в Staged
git reset --mixed HEAD~1	Удаляет последний коммит, изменения остаются в файлах, но не в Staged
git reset --hard HEAD~1	Удаляет последний коммит и изменения из рабочей директории
git reset --hard HEAD~2	Откат на два коммита назад
git reset --hard <hash>	Откат к конкретному коммиту

3. git revert — безопасная отмена коммитов
Команда	Описание
git revert HEAD	Отменяет последний коммит новым коммитом
git revert <hash>	Отменяет конкретный коммит
git revert HEAD~3..HEAD	Отменяет последние три коммитаВажно: revert не удаляет старые коммиты из истории, а создаёт новые отменяющие коммиты.

4. git checkout / git switch — переключениеКоманда	Описание
git checkout <hash>	Переход к конкретному коммиту
git checkout main	Переход на ветку main
git switch main	Современная команда переключения на ветку
git switch --detach <hash>	Просмотр конкретного коммита без переключения на ветку

5. git restore — восстановление файловКоманда	Описание
git restore file.py	Отменяет незакоммиченные изменения файла
git restore --staged file.py	Убирает файл из Staged, сохраняя изменения
git restore --source=<hash> file.py	Восстанавливает файл из конкретного коммита
